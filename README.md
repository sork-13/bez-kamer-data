# База камер «Без камер»

Камеры фотовидеофиксации, посты ДПС и пункты оплаты платных дорог по всей России.
Используется приложением «Без камер».

## Источники

1. **OpenStreetMap**: камеры (`highway=speed_camera`), связи `type=enforcement`, посты
   (`police=checkpoint`), пункты оплаты (`barrier=toll_booth`).
2. **Госавтоинспекция**: перечни мест установки камер, которые регионы публикуют
   на госавтоинспекция.рф по 257-ФЗ (PDF и Excel). Из них берутся координаты и виды нарушений.

Точки одного типа ближе 40 м склеиваются в одну. База собирается заново каждую ночь
(04:00 по Москве) заданием `.github/workflows/update-road-data.yml`.
Вручную: `npm ci && node scripts/build-db.mjs`.

## Формат

`data/road-objects.json`:

```json
{ "version": "2026-11-03T15:00:00.000Z", "source": "...", "rows": [["camera", 55.75, 37.61, 60, 180, 3, 3]] }
```

Каждая строка:

| Поле | Значение |
|---|---|
| тип | `camera`, `tripod` (места передвижных камер из перечней ГАИ), `police`, `toll` |
| широта, долгота | WGS 84 |
| ограничение | км/ч или `null` |
| направление | направление камеры в градусах или `null` |
| нарушения | битовая маска, см. `scripts/features.mjs` (1 - скорость, 2 - светофор, 4 - стоп-линия, ...) |
| источники | битовая маска: 1 - OpenStreetMap, 2 - Госавтоинспекция |

`version` меняется, только когда данные действительно изменились.
