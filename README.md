# База камер «Без камер»

Камеры контроля скорости, посты ДПС и пункты оплаты платных дорог по всей России,
а также платные парковки Москвы и Санкт-Петербурга. Используется приложением «Без камер».

База обновляется автоматически каждую ночь (04:00 по Москве) заданием
`.github/workflows/update-road-data.yml`. Вручную: `node scripts/import-osm.mjs`.

## Формат

`data/road-objects.json`:

```json
{ "version": "2026-11-03T15:00:00.000Z", "source": "...", "rows": [["camera", 55.75, 37.61, 60, 180]] }
```

Каждая строка: тип (`camera`, `police`, `toll`, `parking`), широта, долгота,
ограничение скорости в км/ч или `null`, направление камеры в градусах или `null`.
`version` меняется, только когда данные действительно изменились.
